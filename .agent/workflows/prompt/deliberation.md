---

복잡한 문제 해결, 의사결정, 전략 수립 시 **체계적이고 다각적인 사고 과정**을 거쳐 깊이 있는 분석을 수행하는 워크플로우입니다.

## 🎯 적용 상황

- 비즈니스 의사결정
- 창의적 문제해결
- 윤리적 딜레마
- 연구 및 학습
- 전략 수립

> ⚠️ **주의**: 간단한 사실 확인이나 단순 정보 요청에는 불필요합니다.

## 🔄 Workflow Process

### Phase 1: 간과한 정보 파악

1. **누락 정보 점검**
   ```
   이 문제에 대해 답변하기 전에:
   - 내가 놓치고 있는 중요한 정보나 맥락이 있는가?
   - 암묵적으로 가정하고 있는 것은 무엇인가?
   - 추가로 고려해야 할 요소가 있는가?
   ```

2. **인지적 편향 점검**
   | 편향 유형 | 점검 질문 |
   |----------|----------|
   | 확증 편향 | 내 기존 믿음을 확인하는 정보만 찾고 있지 않은가? |
   | 가용성 휴리스틱 | 쉽게 떠오르는 사례에만 의존하고 있지 않은가? |
   | 앵커링 | 처음 받은 정보에 과도하게 의존하고 있지 않은가? |
   | 후견 지혜 | 결과를 알고 나서 판단하고 있지 않은가? |

### Phase 2: 다양한 이해관계자 입장 고려

1. **이해관계자 대변**
   ```
   각 이해관계자의 입장에서 이 결정이 어떤 영향을 미치는지 분석:
   
   - 직접 영향 받는 사람: [관점 분석]
   - 간접 영향 받는 사람: [관점 분석]
   - 의사결정자: [관점 분석]
   - 미래 세대: [관점 분석]
   ```

2. **포괄적 해결책 모색**
   - 가장 취약한 이해관계자를 우선 고려
   - 장단기 영향 균형 맞추기

### Phase 3: 가정 검토

1. **암묵적 가정 명확화**
   ```
   이 답변/해결책은 다음과 같은 가정을 바탕으로 합니다:
   
   가정 1: [가정 내용]
   - 이 가정이 참일 확률: [높음/중간/낮음]
   - 이 가정이 틀리다면: [대안적 시나리오]
   
   가정 2: [가정 내용]
   - 이 가정이 참일 확률: [높음/중간/낮음]
   - 이 가정이 틀리다면: [대안적 시나리오]
   ```

2. **시나리오 분석**
   | 시나리오 | 핵심 가정 변화 | 결과 예측 | 대응 방안 |
   |---------|--------------|----------|----------|
   | 최선 | ... | ... | ... |
   | 중간 | ... | ... | ... |
   | 최악 | ... | ... | ... |

### Phase 4: 종합적 판단

1. **증거 가중치 평가**
   - 각 논점의 증거 강도 평가
   - 불확실성 수준 명시

2. **최종 결론 도출**
   ```markdown
   ## 🎯 심사 숙고 결과
   
   ### 분석 대상
   [문제/의사결정 설명]
   
   ### 검토 과정
   - [x] 간과한 정보 점검
   - [x] 인지적 편향 확인
   - [x] 이해관계자 입장 고려
   - [x] 가정 검토
   
   ### 핵심 통찰
   1. ...
   2. ...
   
   ### 권고 사항
   [결론 및 권고]
   
   ### 주의사항 및 제약
   - ...
   
   ### 추가 고려 필요 사항
   - ...
   ```

## 💡 프롬프트 템플릿

```
다음 문제에 대해 심사 숙고하여 답변해주세요:

[문제/의사결정 설명]

답변 시 다음을 포함해주세요:
1. 이 문제에서 간과하기 쉬운 중요한 정보가 있다면 먼저 파악해주세요
2. 관련된 다양한 이해관계자들의 입장을 각각 대변해주세요
3. 당신의 답변이 기반하고 있는 암묵적 가정을 명확히 하고, 
   그 가정이 틀릴 경우 어떤 대안적 시나리오가 필요한지 설명해주세요
4. 최종적으로 균형 잡힌 권고를 제시해주세요
```

## ✅ 체크리스트

심사 숙고 기법 적용 시 확인사항:

- [ ] 간과한 정보를 파악했는가?
- [ ] 인지적 편향을 점검했는가?
- [ ] 다양한 이해관계자 입장을 고려했는가?
- [ ] 암묵적 가정을 명확히 했는가?
- [ ] 가정이 틀릴 경우의 대안을 제시했는가?
- [ ] 불확실성 수준을 명시했는가?
