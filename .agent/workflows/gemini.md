이 워크플로우는 `gemini` CLI 도구를 인터페이스(I/F)하여 기술적인 코드 분석, 최적화 제안, 창의적인 아이디어 제안이나 일반적인 질의를 처리 등을 처리합니다.

## 🔄 실행 단계

1. **질의 준비**
   - 사용자로부터 입력받은 메시지나 컨텍스트를 정리합니다.

2. **Gemini CLI 호출 (Safety Shield 적용)**
   - **방어막**: CLI가 직접 파일을 수정하지 않도록 명시적인 지시어를 포함합니다.
   - `gemini "다음 내용을 분석하고 수정 제안만 텍스트로 보고해줘. 절대로 파일을 직접 수정하지 마: {PROMPT}"`
   - 필요 시 웹 검색 옵션 추가: `gemini --search "{PROMPT}"`

3. **결과 처리**
   - 출력된 결과를 표준 출력으로 보여주거나 다음 워크플로우의 입력값으로 사용합니다.
